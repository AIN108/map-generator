# 캠퍼스 조감도 생성기

시드 하나로 대학 캠퍼스 조감도를 만드는 브라우저 앱입니다. 건물 배치, 도로, 조경, 상징물, 번호 붙은 안내 라벨, 제목과 범례까지 한 장에 그립니다. 같은 시드와 옵션이면 항상 같은 캠퍼스가 나오므로 링크 하나로 공유하거나 TRPG·소설·게임의 무대로 다시 불러 쓸 수 있습니다.

- 남쪽 하늘에서 비스듬히 내려다본 **원근 조감도** (Canvas 2D로 직접 투영)
- 정문 → 벚꽃 중심축 → 중앙광장 → 대학본부(시계탑) → 기념비 → 후문으로 이어지는 중심 구성
- 단과대별 구역(인문·사회·공학·자연·예술·의료·체육·기숙사·국제)에 따라 건물이 모이고, 순환도로·방사형 도로를 따라 앉음
- 건물 모양 13가지(일자·ㄱ자·ㄷ자·ㅁ자 중정, 고전식 본관, 아트리움, 계단식, 쌍둥이 고층, 탑상형, 볼트 지붕 체육관, 원형, 병원, 공연장)와 외관 7가지(붉은 벽돌·석조·유리 커튼월 등)
- 상징물: 분수, 기념탑, 무한의 고리, 세계의 구, 지식의 책, 수학적 곡선, 조각정원, 정문 문장, 동상, 종각, 연못
- 대학 이름 자동 생성(순우리말·한자어·학문 개념어, 실제 대학 이름은 제외)과 영문 표기
- 계절(봄 벚꽃·여름·가을 단풍·겨울 눈), 시간(낮·해질녘·밤 조명), 시점 높이, 주변(숲과 산·도시)
- 확대·이동, 건물 정보 보기, 지도 아래 번호 목록에서 바로 찾아가기
- **편집**: 건물·상징물 옮기기·돌리기·복제·추가·삭제, 이름·번호·종류·외관·모양·층수·크기·방향 바꾸기, 이름표 옮기기·숨기기, 여러 개 묶어 옮기기, 길 그리기·지우기, 나무 심기·베기, 되돌리기
- **도보 거리**: 고른 건물에서 다른 건물·상징물·정문까지 걷는 길과 시간을 지도에 표시
- PNG(3200×2400)·JSON 저장, JSON 불러오기, 이름 붙인 판 저장(브라우저), 현재 옵션이 담긴 공유 링크
- **건물 목록·설정 글로 만들기**: 건물 이름·종류·층수·위치를 한 줄씩 적거나, 소설·TRPG 설정 글(.md·.txt)을 불러오면 시설과 위치를 찾아 그대로 배치. 지도에서 고친 내용은 목록 칸에 다시 적히고, 지금 배치를 위치·층수·도보 시간이 담긴 설정 글로 내보낼 수도 있음

## 실행

Node.js 22.18 이상이 필요합니다 (테스트가 Node의 TypeScript 타입 제거 실행을 씁니다).

```bash
npm ci
npm run dev        # 개발 서버
npm test           # 테스트 (node:test)
npm run build      # dist/ 정적 빌드
```

## 옵션

| 항목 | 설명 |
|---|---|
| 시드 | 같은 시드 → 같은 부지·배치·나무. `무작위`로 새 시드를 뽑습니다. |
| 대학 이름 | 비우면 시드로 짓습니다. 바꾸면 '○○대학교병원' 같은 건물 이름도 따라 바뀝니다. |
| 건물 수 | 10~32동. 많을수록 캠퍼스가 커지고, 중요도가 높은 건물부터 들어갑니다. 자리가 모자라면 몇 동 적게 놓일 수 있습니다. |
| 의과대학·대학병원 | 끄면 병원·의대·간호대·약대를 넣지 않습니다. |
| 계절·시간·시점·주변 | 배치는 그대로 두고 보기만 바뀝니다 (편집 내용 유지). |

## 건물 목록·설정 글로 만들기

패널의 `건물 목록·설정 글로 만들기`를 열고 한 줄에 건물 하나씩 적은 뒤 `이 목록으로 생성`을 누릅니다. 적은 순서가 번호가 됩니다.

```
@이름 한빛대학교
@크기 700x600
대학본부 | 본부 | 5층 | 중앙
중앙광장 | 광장
중앙도서관 | 8층 | 중앙광장 동쪽 | 유리
학생회관 | 중앙광장 서쪽
다산관 | 인문 | 5층 | 북서쪽 | 벽돌
율곡관 | 다산관 남쪽
제1공학관 | 9층 | 동쪽
제2공학관 | 제1공학관 동쪽
사범대 본관 | 다산관과 율곡관 사이
한빛학사 | 기숙사 | 12층 | 남쪽 외곽
종합체육관 | 남서쪽
야외 운동장 | 종합체육관 뒤 | 번호 없음
@상징물 소형 분수 | 분수 | 중앙광장 동쪽
@상징물 개교 기념탑 | 기념석 | 대학본부 북쪽
```

| 칸 | 쓰는 법 |
|---|---|
| 종류 | 본부·광장·도서관·학생회관·체육관·운동장·병원·기숙사·국제기숙사·공학·소프트웨어·자연과학·인문·사회과학·사범·경영·법학·국제·국제교류·의학·간호·간호실습·예술·예술실습·음악·강당·박물관 등. 비우면 이름으로 짐작하고, 모르는 이름(예: 다산관)은 일반 강의동입니다. |
| 층수 | `8층` |
| 위치 | 캠퍼스 기준 `남동쪽`·`남동쪽 외곽`·`중앙 북동쪽`, 건물 기준 `중앙광장 동쪽`·`국제관 옆`·`중앙도서관 뒤`·`국제관 앞`·`A와 B 사이`. 둘을 함께 써도 됩니다(`북동쪽 외곽, 국제관 옆`). 기준은 목록에 있는 이름이어야 합니다. |
| 외관 | 벽돌·석재·유리·흰색·콘크리트·현대·고전 |
| 번호 없음 | 그리되 번호·범례에서 뺍니다 (공식 시설이 아닌 운동장 등). |
| `@이름`·`@크기`·`@상징물` | 대학 이름, 캠퍼스 동서×남북(m, 건물이 많으면 자동 배치 크기까지 넓힘), 상징물(분수·기념석·고리·지구본·책·곡선·조각정원·문장·동상·종·연못 + 위치) |
| 자리 고정 | `좌표 120,-45`(m, x 동쪽·y 남쪽), `각도 30`, `크기 60x24`(폭×깊이 m), `모양 ㄱ자`(일자·ㄱ자·ㄷ자·ㅁ자 등), `세부 0.42`. 좌표가 있으면 위치 묘사보다 앞서고 겹침 검사 없이 그 자리에 놓습니다. 상징물도 `@상징물 이름 \| 종류 \| 위치 \| 좌표 x,y`로 고정합니다. |
| `@부지` | `@부지 25`는 부지(도로망)를 건물 25동 기준 크기로 고정합니다. 건물을 지우거나 더해도 도로가 다시 짜이지 않습니다. `@부지 자동 24`는 자동 배치의 24동 부지와 똑같이 만듭니다. |

- 본부는 캠퍼스 중앙, 광장은 그 남쪽에 고정되고, '광장(또는 본부) 동쪽·서쪽'이라고 적은 건물은 광장 양옆에 섭니다. 나머지는 위치 묘사를 목표 지점으로 바꿔 가장 가까운 도로변 빈자리에 놓습니다. 기준 건물을 놓은 뒤 그 건물을 기준으로 삼은 건물을 곧바로 이어서 놓으므로 '병원 옆 의대' 같은 묶음이 흩어지지 않습니다. 서로를 기준으로 삼아도(A는 B 옆, B는 A 옆) 끝까지 놓습니다.
- '옆·앞·뒤·사이·방향'처럼 기준 건물에 붙는 관계는 도로변이 아니어도 기준 건물 둘레의 빈자리에 같은 방향으로 나란히 놓습니다. 목표 가까이에 자리가 없으면 건물을 조금 줄여 보고, 그래도 없으면 더 멀리서 찾습니다. 끝내 놓지 못한 건물은 목록 아래에 알려 줍니다. 층수가 종류의 보통 층수보다 높으면 바닥을 줄이고, 훨씬 높으면 고층형 모양으로 바꿉니다.
- **설정 글 불러오기**: `파일 불러오기`로 마크다운·텍스트 설정 글을 열면 제목(`#`)이 건물 이름이고 본문에 층수·'건물'·'야외 공간' 같은 말이 있는 절을 시설로 보고, 그 절 첫 문장에서 위치(`○○ 동쪽의`, `캠퍼스 남동쪽 외곽의`, `A와 B 사이의`)·지상 층수·외관(벽돌·석재·유리·흰색·금속)을 읽습니다. 단과대학 같은 조직, 온라인 커뮤니티, '변경 기록' 같은 절은 건너뜁니다. 상징물은 따옴표로 묶은 이름이나 '분수'·'기념석' 같은 말이 나오는 문장의 '…에는' 앞 위치로 찾고, 본문에 운동장이 나오면 번호 없는 운동장을 체육관 가까이에 둡니다. 결과는 목록 형식으로 칸에 채워지므로 확인하고 고친 뒤 생성합니다. 이 추출은 규칙 기반이라 글 형식에 따라 놓치는 내용이 있을 수 있습니다.
- 목록을 쓰는 동안에는 건물 수·병원 옵션이 꺼지고, 시드는 도로 모양·건물 세부·나무 같은 나머지를 정합니다. 목록은 이 브라우저와 JSON 저장 파일에 담기고, 공유 링크에는 담기지 않습니다. `자동 배치로`로 목록을 지웁니다.
- **지도와 맞추기**: 목록으로 만든 뒤 지도에서 고치면 목록 칸이 따라 바뀝니다. 손으로 옮기거나 크기·모양·방향을 바꾼 건물에는 좌표·각도·크기·모양이 붙어, 목록을 다시 적용해도 그 자리에 놓입니다. 이름을 바꾸면 그 건물을 기준으로 삼던 다른 줄의 이름도 바뀌고, 지운 건물을 기준으로 삼던 줄은 그 기준이 빠집니다. 목록 칸에 글을 쓰는 동안에는 덮어쓰지 않습니다. 그린 길·지운 도로·나무 편집은 목록과 따로 저장되며, 목록을 다시 적용해도 남습니다.
- `지금 배치를 목록으로`는 자동 배치(또는 편집한 배치)를 모든 건물이 좌표로 고정된 목록으로 옮깁니다. `이 목록으로 생성`을 누르면 같은 배치 그대로 목록 모드가 됩니다. 좌표 칸을 지운 줄은 위치 묘사대로 다시 놓입니다.

## 설정 글로 내보내기

`설정 글로 내보내기`는 지금 배치를 마크다운 설정 글(`대학이름_캠퍼스배치.md`)로 저장합니다. 캠퍼스 구역별 개요, 정문·중앙광장에서 각 시설까지 걷는 시간 표, 시설마다 "○○관은 캠퍼스 북동쪽, 중앙도서관 동쪽의 지상 5층 붉은 벽돌 건물이다." 같은 문장, 상징물 위치를 적습니다. 이 글은 `파일 불러오기`로 다시 읽을 수 있게 쓰여 있어, 위치·층수·외관이 다시 목록이 됩니다. 소설·TRPG 설정의 초안으로 고쳐 쓰는 용도입니다.

## 보기

- 마우스 휠·`+`·`-`·`0`, 지도 오른쪽 위 버튼(좁은 화면에서는 지도 아래)으로 확대·축소합니다 (100%~800%).
- 왼쪽 버튼으로 끌어서 옮깁니다. 편집 모드에서는 `스페이스바`를 누른 채 끌거나 가운데·오른쪽 버튼으로 끕니다. 터치 화면에서는 두 손가락으로 확대·이동합니다.
- 건물·상징물에 마우스를 올리면 정보 창에 번호·용도·층수·바닥 크기·연면적·외관이 나옵니다. 누르면 선택되어 패널에서 바꿀 수 있고(아래 '고른 건물'), 지도 위에 돌리기·복제·지우기 막대가 뜹니다.
- **도보 거리**: 고른 건물 칸의 `도보 거리`에서 목적지(정문·후문·다른 건물·상징물)를 고르거나 `지도에서`를 누르고 지도의 목적지를 누르면, 출입구 사이의 걷는 길을 지도에 그리고 거리·시간(분속 80m)을 알려 줍니다. 길은 4m 격자에서 건물을 피해 찾고, 도로·산책로·포장 마당을 잔디밭보다 조금 더 좋아합니다.
- 라벨은 확대해도 화면에서 같은 크기로 그리고, 겹치면 이름 대신 번호만 둡니다. 확대할수록 가려졌던 이름이 드러납니다. 확대 중이거나 휴대폰처럼 좁은 화면에서는 지도 안 범례를 숨기고 지도 아래 번호 목록을 씁니다.
- `PNG 저장`은 보고 있는 화면과 관계없이 전체를 3200×2400으로 저장합니다 (제목·범례·라벨 표시 설정을 따릅니다).

## 편집

`편집 모드`(단축키 `E`)를 켜고 도구를 고릅니다.

| 도구 | 동작 |
|---|---|
| 선택·이동 | 건물·상징물을 끌어서 옮깁니다. 끄는 동안 실제로 놓일 자리를 초록 상자로 보여 주고(커서 자리가 막혔으면 흰 점선이 커서 자리, 초록이 붙을 자리), 빈자리가 없으면 빨강입니다. 높은 건물은 잡은 높이를 기준으로 움직여 커서를 따라옵니다. |
| 건물 추가 | 누른 자리에 고른 건물을 놓습니다. 마우스를 올리면 놓일 자리가 미리 보입니다. 정면이 남쪽을 보게 놓고, 안 맞으면 90°씩 돌려 봅니다. |
| 상징물 추가 | 누른 자리에 고른 상징물을 놓습니다. |
| 길 그리기 | 도로·산책로를 점을 찍어 그립니다 (아래 '길·나무'). |
| 나무 | 칠한 곳에 나무를 심거나 벱니다. |
| 지우기 | 누른 건물·상징물을 지웁니다. 건물이 없는 곳의 길을 누르면 그 길을 지웁니다. |

- 막힌 자리에 놓으면 **가장 가까운 빈자리에 붙여** 놓습니다 (옮기기는 45m + 건물 크기의 절반, 추가는 60m + 절반 안에서 찾음). 얼마나 옆으로 붙였는지 상태 줄에 알려 줍니다. 돌릴 때도 막히면 가까운 자리로 조금 옮겨 돌립니다.
- 손 편집 기준: 건물은 순환도로 안쪽에, 다른 건물과 4m 이상, 도로 가장자리와 1.5m 이상 떨어뜨립니다 (자동 생성은 10m·4m로 더 넉넉함). 중심축 산책로·정문 앞·기념비 둘레에는 두지 않습니다.
- **자유 배치**를 켜면 캠퍼스 경계 안이기만 하면 건물·도로와 겹쳐도 누른 자리에 그대로 놓습니다.
- 편집 모드에서도 빈 곳을 끌면 지도가 움직이고, 끌지 않고 누르면 도구가 그 자리에 쓰입니다. 편집 모드가 아닐 때 건물을 끌면 지도가 움직인다고 한 번 알려 줍니다.
- 번호는 목록 순서입니다. 건물을 지우면 뒤 번호가 하나씩 당겨지고, 새 건물은 마지막 번호를 받습니다.
- 나무·산책로·주차장·포장 마당은 배치에서 저절로 계산합니다. 건물을 옮기면 빈 자리에는 나무가 다시 자라고 새 자리의 나무는 치워집니다 (나무 후보 자리는 시드로 고정).
- 되돌리기 `Ctrl+Z`, 다시 하기 `Ctrl+Shift+Z`·`Ctrl+Y` (최근 60단계). 방향키로 잇달아 옮긴 것은 한 단계로 묶입니다.
- 편집한 배치는 이 브라우저에 자동 저장되어 새로고침해도 남습니다. 공유 링크에는 담기지 않으므로 다른 사람에게 보내려면 `JSON 저장` → `JSON 불러오기`를 쓰세요. 시드·건물 수·병원 설정을 바꾸면 편집 내용이 사라지므로 확인 창이 뜹니다.

### 고른 건물

건물을 누르면 패널에 다음 칸이 나옵니다 (편집 모드가 아니어도 바꿀 수 있습니다).

| 칸 | 동작 |
|---|---|
| 이름 | 바꾸면 범례·라벨·목록의 기준 이름이 함께 바뀝니다. |
| 번호 | 숫자를 적거나 ▲▼로 범례 순서를 바꿉니다. 운동장 같은 번호 없는 시설은 비어 있습니다. |
| 종류·외관·모양 | 종류를 바꾸면 그 종류의 설명·정보로 바뀝니다(모양·크기는 그대로). 모양은 일자·ㄱ자·ㄷ자·ㅁ자 중정·날개형·아트리움·계단식·쌍둥이·탑상형 등. |
| 방향·층수·폭·깊이 | 방향은 도(°), 정면이 남쪽일 때 0°. 막히는 값이면 가까운 자리로 조금 옮겨 맞추고, 그래도 안 되면 알려 줍니다. |
| 복제 | 같은 건물을 옆 빈자리에 하나 더 놓습니다 (`Ctrl+D`). |
| 이름표 | 숨기거나, 편집 모드에서 이름표를 끌어 옮긴 자리를 되돌립니다. |
| 도보 거리 | 위 '보기' 참고. |

단축키: 방향키 1m(`Shift` 5m) 옮기기(막히면 그 앞에서 멈춤), `R`·`Shift+R` 15° 돌리기, `Ctrl+D` 복제, `Delete` 지우기, `Esc` 선택 해제.

### 이름표·여러 개 고르기

- 편집 모드의 선택·이동 도구에서 지도 위 이름표를 끌면 이름표만 옮겨집니다(지시선으로 건물과 이어짐). 옮긴 이름표는 겹침 회피보다 앞서 그 자리에 그립니다.
- `Shift`를 누른 채 누르면 여러 건물·상징물을 묶어 고르고, `Shift`를 누른 채 빈 곳을 끌면 상자 안의 것을 모두 고릅니다. 묶음 중 하나를 끌거나 방향키를 누르면 함께 움직이고, `R`은 각자 제자리에서 돌리며, `Delete`는 함께 지웁니다. 묶음은 모양을 유지한 채 전체가 들어갈 수 있을 때만 움직입니다 (끌어 놓은 자리가 막혔으면 가까운 자리를 찾고, 방향키는 막히면 멈춤).

### 길·나무

- **길 그리기**: 도로(차도, 폭 9m)나 산책로(폭 4m)를 고르고 지도를 눌러 점을 찍습니다. 두 번 누르거나 `Enter`로 끝내고, `Backspace`로 마지막 점을, `Esc`로 전체를 취소합니다. 그린 도로 위에는 건물을 둘 수 없고, 걷는 길 찾기에도 쓰입니다.
- **지우기** 도구로 건물이 없는 곳의 길을 누르면 그린 길은 지워지고, 캠퍼스 안 도로·연결로는 숨겨집니다(순환도로·간선도로는 지울 수 없음). `지운 캠퍼스 도로 되살리기`로 모두 되돌립니다.
- **나무**: 붓(심기·베기)과 반경을 고르고 누르거나 끌어서 칠합니다. 벤 곳은 자동으로 자라는 나무와 숲도 치우고, 나중에 칠한 것이 앞선 것을 덮습니다.

### 저장해 둔 판

`저장해 둔 판`을 열고 이름을 적어 `저장`하면 지금 상태(배치·편집·건물 목록·계절·시간·시점·주변)를 이 브라우저에 남깁니다. 이름을 비우면 '대학이름 1'처럼 짓고, 같은 이름이면 확인 후 바꿉니다. 최대 20개이며 넘치면 가장 오래된 판부터 지웁니다. 목록에서 골라 `불러오기`(또는 두 번 누르기)·`지우기`를 합니다. 저장하지 않은 편집이 있으면 불러오기 전에 묻습니다. 브라우저 데이터를 지우면 함께 사라지므로, 오래 보관하거나 다른 기기로 옮길 판은 `JSON 저장`을 쓰세요.

## JSON 형식

`JSON 저장`은 `campus-map/v1` 형식으로 옵션(시드·건물 수·병원·계절·시간·시점·주변, 목록을 썼다면 그 목록 글)과 배치(대학 이름, 번호 순서대로의 건물·광장·운동장 — 종류·이름·중심 좌표(m)·회전·폭·깊이·층수·외관·모양·손으로 고정했는지·이름표 위치, 상징물 — 종류·이름·좌표, 그린 길·숨긴 도로 번호·심은 곳·벤 곳)를 담습니다. 저장해 둔 판도 같은 형식입니다. 불러올 때 모든 값을 검사하고, 범위를 벗어나거나 알 수 없는 종류가 있으면 거부합니다.

## 배포

`main`에 푸시하면 GitHub Actions가 타입 검사·테스트·빌드 후 GitHub Pages에 배포합니다. 처음 한 번은 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해야 합니다.
