# 캠퍼스 조감도 생성기

시드 하나로 대학 캠퍼스 조감도를 만드는 브라우저 앱입니다. 건물 배치, 도로, 조경, 상징물, 번호 붙은 안내 라벨, 제목과 범례까지 한 장에 그립니다. 같은 시드와 옵션이면 항상 같은 캠퍼스가 나오므로 링크 하나로 공유하거나 TRPG·소설·게임의 무대로 다시 불러 쓸 수 있습니다.

- 남쪽 하늘에서 비스듬히 내려다본 **원근 조감도** (Canvas 2D로 직접 투영)
- 정문 → 벚꽃 중심축 → 중앙광장 → 대학본부(시계탑) → 기념비 → 후문으로 이어지는 중심 구성
- 단과대별 구역(인문·사회·공학·자연·예술·의료·체육·기숙사·국제)에 따라 건물이 모이고, 순환도로·방사형 도로를 따라 앉음
- 캠퍼스 유형 3가지(전원형·도심 격자형·강변형)와 밀도(여유·보통·촘촘)
- 건물 모양 13가지(일자·ㄱ자·ㄷ자·ㅁ자 중정, 고전식 본관, 아트리움, 계단식, 쌍둥이 고층, 탑상형, 볼트 지붕 체육관, 원형, 병원, 공연장)와 칸마다 층수를 칠하는 자유형, 외관 7가지(붉은 벽돌·석조·유리 커튼월 등)
- 상징물: 분수, 기념탑, 무한의 고리, 세계의 구, 지식의 책, 수학적 곡선, 조각정원, 정문 문장, 동상, 종각, 연못
- 대학 이름 자동 생성(순우리말·한자어·학문 개념어, 실제 대학 이름은 제외)과 영문 표기
- 계절(봄 벚꽃·여름·가을 단풍·겨울 눈), 시간(낮·해질녘·밤 조명), 시점 높이, 주변(숲과 산·도시)
- 확대·이동, 건물 정보 보기, 지도 아래 번호 목록에서 바로 찾아가기
- **편집**: 건물·상징물 옮기기·돌리기·복제·추가·삭제, 이름·번호·종류·외관·모양·층수·크기·방향 바꾸기, 평면도에서 날개 폭·뒤 동 깊이·저층부·지붕 조절과 칸마다 층수를 칠하는 자유형 평면, 이름표 옮기기·숨기기, 여러 개 묶어 옮기기, 길 그리기·지우기, 나무 심기·베기, 정렬 안내선, 되돌리기(기록 목록)
- **건물 안 층 평면**: 층마다 복도·실·계단을 자동으로 나누고 호실 번호를 매김. 호실에 이름을 붙일 수 있음
- **메모 핀**: 사건 장소·동아리방 같은 메모를 지도에 꽂아 조감도·배치도·설정 글에 함께 담음
- **도보 거리**: 고른 건물에서 다른 건물·상징물·정문까지 걷는 길과 시간을 지도에 표시
- 조감도·위에서 본 **배치도**(축척·방위·좌표 격자·번호 목록)를 PNG(기본·1.5배·2배) 또는 SVG(벡터)로 저장, JSON 저장·불러오기, 이름 붙인 판 저장(브라우저), 편집한 배치까지 담는 공유 링크
- **건물 목록·설정 글로 만들기**: 건물 이름·종류·층수·위치를 한 줄씩 적거나, 소설·TRPG 설정 글(.md·.txt)을 불러오면 시설과 위치를 찾아 그대로 배치. 지도에서 고친 내용은 목록 칸에 다시 적히고, 지금 배치를 위치·층수·도보 시간이 담긴 설정 글로 내보낼 수도 있음. 원하면 자기 Anthropic API 키로 Claude에게 설정 글을 읽힐 수 있음(선택)

## 실행

Node.js 22.18 이상이 필요합니다 (테스트가 Node의 TypeScript 타입 제거 실행을 씁니다).

```bash
npm ci
npm run dev        # 개발 서버
npm test           # 테스트 (node:test)
npm run build      # dist/ 정적 빌드
npm run test:e2e   # 브라우저 점검 (빌드한 앱을 Playwright Chromium으로 연다)
```

- `npm run test:e2e`는 Playwright의 Chromium이 필요합니다 (`npx playwright install chromium`). CI에서는 매번 설치해 돌립니다.
- `test/render.test.ts`는 몇 가지 시드·보기의 그리기 목록 요약을 `test/golden/drawlist.json`과 비교합니다. 그림을 일부러 바꿨다면 `UPDATE_GOLDEN=1 npm test`로 저장값을 새로 씁니다.

## 옵션

| 항목 | 설명 |
|---|---|
| 시드 | 같은 시드 → 같은 부지·배치·나무. `무작위`로 새 시드를 뽑습니다. |
| 대학 이름 | 비우면 시드로 짓습니다. 바꾸면 '○○대학교병원' 같은 건물 이름도 따라 바뀝니다. |
| 건물 수 | 10~32동. 많을수록 캠퍼스가 커지고, 중요도가 높은 건물부터 들어갑니다. 자리가 모자라면 몇 동 적게 놓일 수 있습니다. |
| 의과대학·대학병원 | 끄면 병원·의대·간호대·약대를 넣지 않습니다. |
| 캠퍼스 유형 | **전원형**: 타원 경계·순환도로·방사형 길 (예전과 같은 배치). **도심 격자형**: 둥근 사각형 경계와 150 m 간격 바둑판 길. **강변형**: 동서로 긴 캠퍼스, 동서 간선 두 줄, 북쪽에 흐르는 강(조감도·배치도에 그려지고 강가는 평지). 격자형·강변형에서는 테니스·농구 코트, 주차빌딩, 학생식당도 자동으로 들어갈 수 있습니다. 바꾸면 바로 새로 만듭니다. |
| 밀도 | 같은 건물 수에서 캠퍼스 크기 배율 (여유 1.12·보통 1·촘촘 0.94). 촘촘하면 자리가 모자라 몇 동 덜 놓일 수 있고, 그때는 상태 줄에 알려 줍니다. |
| 계절·시간·시점·주변 | 배치는 그대로 두고 보기만 바뀝니다 (편집 내용 유지). |

유형·밀도가 기본값(전원형·보통)이 아니면 링크에 `campus=`·`density=`가 붙습니다.

## 건물 목록·설정 글로 만들기

패널의 `건물 목록·설정 글로 만들기`를 열고 한 줄에 건물 하나씩 적은 뒤 `이 목록으로 생성`을 누릅니다. 적은 순서가 번호가 됩니다.

```
@이름 한빛대학교
@크기 700x600
대학본부 | 본부 | 5층 | 중앙
중앙광장 | 광장
중앙도서관 | 8층 | 중앙광장 동쪽 | 유리
학생회관 | 중앙광장 서쪽
다산관 | 인문 | 5층 | 북서쪽 | 벽돌
율곡관 | 다산관 남쪽
제1공학관 | 9층 | 동쪽
제2공학관 | 제1공학관 동쪽
사범대 본관 | 다산관과 율곡관 사이
한빛학사 | 기숙사 | 12층 | 남쪽 외곽
종합체육관 | 남서쪽
야외 운동장 | 종합체육관 뒤 | 번호 없음
@상징물 소형 분수 | 분수 | 중앙광장 동쪽
@상징물 개교 기념탑 | 기념석 | 대학본부 북쪽
```

| 칸 | 쓰는 법 |
|---|---|
| 종류 | 본부·광장·도서관·학생회관·체육관·운동장·병원·기숙사·국제기숙사·공학·소프트웨어·자연과학·인문·사회과학·사범·경영·법학·국제·국제교류·의학·간호·간호실습·예술·예술실습·음악·강당·박물관·식당·주차·코트 등. 비우면 이름으로 짐작하고, 모르는 이름(예: 다산관)은 일반 강의동입니다. |
| 층수 | `8층` |
| 위치 | 캠퍼스 기준 `남동쪽`·`남동쪽 외곽`·`중앙 북동쪽`, 건물 기준 `중앙광장 동쪽`·`국제관 옆`·`중앙도서관 뒤`·`국제관 앞`·`A와 B 사이`. 둘을 함께 써도 됩니다(`북동쪽 외곽, 국제관 옆`). 기준은 목록에 있는 이름이어야 합니다. |
| 외관 | 벽돌·석재·유리·흰색·콘크리트·현대·고전 |
| 번호 없음 | 그리되 번호·범례에서 뺍니다 (공식 시설이 아닌 운동장 등). |
| `@이름`·`@크기`·`@상징물` | 대학 이름, 캠퍼스 동서×남북(m, 건물이 많으면 자동 배치 크기까지 넓힘), 상징물(분수·기념석·고리·지구본·책·곡선·조각정원·문장·동상·종·연못 + 위치) |
| 자리 고정 | `좌표 120,-45`(m, x 동쪽·y 남쪽), `각도 30`, `크기 60x24`(폭×깊이 m), `모양 ㄱ자`(일자·ㄱ자·ㄷ자·ㅁ자·자유형 등), `세부 0.42`, `형태 …`·`평면 …`(아래 '평면도·모양 편집'). 좌표가 있으면 위치 묘사보다 앞서고 겹침 검사 없이 그 자리에 놓습니다. 상징물도 `@상징물 이름 \| 종류 \| 위치 \| 좌표 x,y`로 고정합니다. |
| `@부지` | `@부지 25`는 부지(도로망)를 건물 25동 기준 크기로 고정합니다. 건물을 지우거나 더해도 도로가 다시 짜이지 않습니다. `@부지 자동 24`는 자동 배치의 24동 부지와 똑같이 만듭니다. |

- 본부는 캠퍼스 중앙, 광장은 그 남쪽에 고정되고, '광장(또는 본부) 동쪽·서쪽'이라고 적은 건물은 광장 양옆에 섭니다. 나머지는 위치 묘사를 목표 지점으로 바꿔 가장 가까운 도로변 빈자리에 놓습니다. 기준 건물을 놓은 뒤 그 건물을 기준으로 삼은 건물을 곧바로 이어서 놓으므로 '병원 옆 의대' 같은 묶음이 흩어지지 않습니다. 서로를 기준으로 삼아도(A는 B 옆, B는 A 옆) 끝까지 놓습니다.
- '옆·앞·뒤·사이·방향'처럼 기준 건물에 붙는 관계는 도로변이 아니어도 기준 건물 둘레의 빈자리에 같은 방향으로 나란히 놓습니다. 목표 가까이에 자리가 없으면 건물을 조금 줄여 보고, 그래도 없으면 더 멀리서 찾습니다. 끝내 놓지 못한 건물은 목록 아래에 알려 줍니다. 층수가 종류의 보통 층수보다 높으면 바닥을 줄이고, 훨씬 높으면 고층형 모양으로 바꿉니다.
- **설정 글 불러오기**: `파일 불러오기`로 마크다운·텍스트 설정 글을 열면 제목(`#`)이 건물 이름이고 본문에 층수·'건물'·'야외 공간' 같은 말이 있는 절을 시설로 보고, 그 절 첫 문장에서 위치(`○○ 동쪽의`, `캠퍼스 남동쪽 외곽의`, `A와 B 사이의`)·지상 층수·외관(벽돌·석재·유리·흰색·금속)을 읽습니다. 단과대학 같은 조직, 온라인 커뮤니티, '변경 기록' 같은 절은 건너뜁니다. 상징물은 따옴표로 묶은 이름이나 '분수'·'기념석' 같은 말이 나오는 문장의 '…에는' 앞 위치로 찾고, 본문에 운동장이 나오면 번호 없는 운동장을 체육관 가까이에 둡니다. 시설 제목이 하나도 없는 글(소설 본문 같은 서술)이면 문장 속 '…관'·'…센터'·'…학사'·'기숙사 A동' 같은 건물 이름을 찾고, 이름 앞뒤 마디에서 위치('캠퍼스 북쪽에는', '그 옆으로', '…은 도서관 동쪽에 있다')·층수('5층짜리', '지상 4층 건물'; '3층 강의실'은 층수로 보지 않음)·외관을 읽습니다. 경찰관·세계관·기관처럼 건물이 아닌 '…관'은 거릅니다. 결과는 목록 형식으로 칸에 채워지므로 확인하고 고친 뒤 생성합니다. 이 추출은 규칙 기반이라 글 형식에 따라 놓치거나 잘못 잡는 내용이 있을 수 있습니다.
- 목록을 쓰는 동안에는 건물 수·병원 옵션이 꺼지고, 시드는 도로 모양·건물 세부·나무 같은 나머지를 정합니다. 목록은 이 브라우저와 JSON 저장 파일, `링크 복사`로 만든 링크에 담깁니다. `자동 배치로`로 목록을 지웁니다.
- **지도와 맞추기**: 목록으로 만든 뒤 지도에서 고치면 목록 칸이 따라 바뀝니다. 손으로 옮기거나 크기·모양·방향을 바꾼 건물에는 좌표·각도·크기·모양이 붙어, 목록을 다시 적용해도 그 자리에 놓입니다. 이름을 바꾸면 그 건물을 기준으로 삼던 다른 줄의 이름도 바뀌고, 지운 건물을 기준으로 삼던 줄은 그 기준이 빠집니다. 목록 칸에 글을 쓰는 동안에는 덮어쓰지 않습니다. 그린 길·지운 도로·나무 편집은 목록과 따로 저장되며, 목록을 다시 적용해도 남습니다.
- `지금 배치를 목록으로`는 자동 배치(또는 편집한 배치)를 모든 건물이 좌표로 고정된 목록으로 옮깁니다. `이 목록으로 생성`을 누르면 같은 배치 그대로 목록 모드가 됩니다. 좌표 칸을 지운 줄은 위치 묘사대로 다시 놓입니다.

## 설정 글로 내보내기

`설정 글로 내보내기`는 지금 배치를 마크다운 설정 글(`대학이름_캠퍼스배치.md`)로 저장합니다. 캠퍼스 구역별 개요, 정문·중앙광장에서 각 시설까지 걷는 시간 표, 시설마다 "○○관은 캠퍼스 북동쪽, 중앙도서관 동쪽의 지상 5층 붉은 벽돌 건물이다." 같은 문장, 상징물 위치를 적습니다. 이 글은 `파일 불러오기`로 다시 읽을 수 있게 쓰여 있어, 위치·층수·외관이 다시 목록이 됩니다. 소설·TRPG 설정의 초안으로 고쳐 쓰는 용도입니다.

## Claude로 설정 글 읽기 (선택)

`건물 목록·설정 글로 만들기` 칸의 `Claude로 설정 글 읽기`를 열고 Anthropic API 키를 넣은 뒤 `Claude로 목록 만들기`를 누르면, 마지막으로 불러온 설정 글(없으면 목록 칸의 글)을 Claude(`claude-opus-5-5`)가 읽어 목록 형식으로 옮깁니다. 규칙 기반 추출이 놓치는 서술형 글에 씁니다.

- 이 앱에는 서버가 없어 **브라우저에서 Anthropic API로 바로** 보냅니다. 글과 키는 Anthropic으로만 가고, 요금은 키 주인에게 청구됩니다. 보내기 전에 글 길이와 어림 토큰·비용을, 끝나면 실제 토큰 수와 어림 비용(입력 $4·출력 $20 / 100만 토큰 기준)을 보여 줍니다.
- 키는 기본으로 저장하지 않습니다. `이 브라우저에 키 기억`을 켜면 이 브라우저의 localStorage에 남습니다 (공용 컴퓨터에서는 켜지 마세요). 링크·JSON·저장해 둔 판에는 담기지 않습니다.
- 구조화 출력으로 목록 글과 참고 사항을 받고, 결과는 직접 입력한 목록처럼 다시 검사해 알아보지 못한 칸은 경고로 보여 줍니다. 확인하고 고친 뒤 `이 목록으로 생성`을 누르세요.
- 안전 분류기가 거절하면 서버가 Anthropic이 권하는 다른 모델로 다시 돌립니다(`fallbacks: "default"`). 응답한 모델이 바뀌면 알려 줍니다. 글은 20만 자까지 보내며, 잘라 보내지는 않습니다.
- 실행 중에는 `취소`로 멈출 수 있습니다. SDK는 이 기능을 쓸 때만 따로 내려받습니다.

## 보기

- 마우스 휠·`+`·`-`·`0`, 지도 오른쪽 위 버튼(좁은 화면에서는 지도 아래)으로 확대·축소합니다 (100%~800%).
- 왼쪽 버튼으로 끌어서 옮깁니다. 편집 모드에서는 `스페이스바`를 누른 채 끌거나 가운데·오른쪽 버튼으로 끕니다. 터치 화면에서는 두 손가락으로 확대·이동합니다.
- 건물·상징물에 마우스를 올리면 정보 창에 번호·용도·층수·바닥 크기·연면적·외관이 나옵니다. 누르면 선택되어 패널에서 바꿀 수 있고(아래 '고른 건물'), 지도 위에 돌리기·복제·지우기 막대가 뜹니다.
- **도보 거리**: 고른 건물 칸의 `도보 거리`에서 목적지(정문·후문·다른 건물·상징물)를 고르거나 `지도에서`를 누르고 지도의 목적지를 누르면, 출입구 사이의 걷는 길을 지도에 그리고 거리·시간(분속 80m)을 알려 줍니다. 길은 4m 격자에서 건물을 피해 찾고, 도로·산책로·포장 마당을 잔디밭보다 조금 더 좋아합니다.
- 라벨은 확대해도 화면에서 같은 크기로 그리고, 겹치면 이름 대신 번호만 둡니다. 확대할수록 가려졌던 이름이 드러납니다. 확대 중이거나 휴대폰처럼 좁은 화면에서는 지도 안 범례를 숨기고 지도 아래 번호 목록을 씁니다.
- `조감도 저장`은 보고 있는 화면과 관계없이 전체를 저장합니다 (제목·범례·라벨·메모 표시 설정을 따릅니다). **형식**은 PNG 또는 SVG, **크기**는 PNG의 픽셀 수로 기본(3200×2400)·1.5배·2배(6400×4800, 약 20MB)입니다. SVG는 확대해도 깨지지 않는 벡터 도면이라 인쇄·편집 프로그램에서 다루기 좋지만, 조감도는 나무가 많아 약 4MB입니다. SVG의 글꼴은 Noto Sans KR·Noto Serif KR을 쓰므로 그 글꼴이 없는 프로그램에서는 다른 글꼴로 보이고, 그림자 효과는 빠집니다. 너무 큰 PNG를 만들 메모리가 없으면 알려 줍니다.
- `배치도 저장`은 위에서 곧게 내려다본 배치도(기본 3600×2400, SVG는 약 0.3MB)입니다. 북쪽이 위이고, 건물은 덩어리별 층수 농도(윗층 윤곽은 점선)와 출입구 점, 도로·산책로·주차장·광장·운동장·나무·캠퍼스 경계(일점쇄선)를 그립니다. 10 m 격자와 50 m 큰 칸(열 A·B…, 행 1·2…), 축척 막대·방위표, 오른쪽 표제란(번호·층수·외관 목록, 상징물, 범례)이 붙습니다. 정보 창과 평면도 표제란의 '배치도 칸'(예: C4)이 이 격자의 칸입니다. TRPG에서 위치·거리를 잴 때 쓰기 좋습니다. 메모 핀은 M1·M2… 번호로 찍히고 표제란에 목록이 붙습니다.

## 편집

`편집 모드`(단축키 `E`)를 켜고 도구를 고릅니다.

| 도구 | 동작 |
|---|---|
| 선택·이동 | 건물·상징물을 끌어서 옮깁니다. 끄는 동안 실제로 놓일 자리를 초록 상자로 보여 주고(커서 자리가 막혔으면 흰 점선이 커서 자리, 초록이 붙을 자리), 빈자리가 없으면 빨강입니다. 높은 건물은 잡은 높이를 기준으로 움직여 커서를 따라옵니다. |
| 건물 추가 | 누른 자리에 고른 건물을 놓습니다. 마우스를 올리면 놓일 자리가 미리 보입니다. 정면이 남쪽을 보게 놓고, 안 맞으면 90°씩 돌려 봅니다. |
| 상징물 추가 | 누른 자리에 고른 상징물을 놓습니다. |
| 길 그리기 | 도로·산책로를 점을 찍어 그립니다 (아래 '길·나무'). |
| 나무 | 칠한 곳에 나무를 심거나 벱니다. |
| 메모 핀 | 누른 자리에 메모 핀을 꽂습니다 (아래 '메모 핀'). |
| 지우기 | 누른 건물·상징물을 지웁니다. 건물이 없는 곳의 길을 누르면 그 길을 지웁니다. |

- 막힌 자리에 놓으면 **가장 가까운 빈자리에 붙여** 놓습니다 (옮기기는 45m + 건물 크기의 절반, 추가는 60m + 절반 안에서 찾음). 얼마나 옆으로 붙였는지 상태 줄에 알려 줍니다. 돌릴 때도 막히면 가까운 자리로 조금 옮겨 돌립니다.
- 손 편집 기준: 건물은 순환도로 안쪽에, 다른 건물과 4m 이상, 도로 가장자리와 1.5m 이상 떨어뜨립니다 (자동 생성은 10m·4m로 더 넉넉함). 중심축 산책로·정문 앞·기념비 둘레에는 두지 않습니다.
- **자유 배치**를 켜면 캠퍼스 경계 안이기만 하면 건물·도로와 겹쳐도 누른 자리에 그대로 놓습니다.
- 편집 모드에서도 빈 곳을 끌면 지도가 움직이고, 끌지 않고 누르면 도구가 그 자리에 쓰입니다. 편집 모드가 아닐 때 건물을 끌면 지도가 움직인다고 한 번 알려 줍니다.
- 번호는 목록 순서입니다. 건물을 지우면 뒤 번호가 하나씩 당겨지고, 새 건물은 마지막 번호를 받습니다.
- 나무·산책로·주차장·포장 마당은 배치에서 저절로 계산합니다. 건물을 옮기면 빈 자리에는 나무가 다시 자라고 새 자리의 나무는 치워집니다 (나무 후보 자리는 시드로 고정).
- 되돌리기 `Ctrl+Z`, 다시 하기 `Ctrl+Shift+Z`·`Ctrl+Y` (최근 60단계). 방향키로 잇달아 옮긴 것은 한 단계로 묶입니다. 되돌리기 버튼 아래 **기록 목록**에 단계마다 무엇을 했는지가 최근 것부터 나오고, 하나를 고르면 그 단계 전까지 한 번에 되돌립니다.
- **정렬 안내선**: 건물을 끌 때 같은 방향(또는 90° 돌린 방향)인 이웃 건물과 가운데선·변이 2.5 m 안으로 맞으면 그 자리로 살짝 당기고 분홍 점선으로 보여 줍니다. `Alt`를 누른 채 끌면 맞추지 않습니다. 막혀서 빈자리로 옮겨지면 안내선은 사라집니다.
- `]`·`[`로 번호 순서대로 다음·앞 건물을 고릅니다 (확대 중이면 그 건물로 옮겨 감).
- 터치 화면에서도 편집 모드에서 손가락으로 건물을 끌어 옮길 수 있습니다.
- 편집한 배치는 이 브라우저에 자동 저장되어 새로고침해도 남습니다. 다른 사람에게 보내려면 `링크 복사`를 쓰세요. 편집한 배치와 건물 목록을 압축해 링크 끝(`&l=…`)에 담습니다 (보통 2~5천 자, 6만 자가 넘으면 `JSON 저장`을 쓰라고 알려 줌). 받은 링크를 열면 JSON을 불러올 때와 같은 검사를 거치고, 그 브라우저에 자동 저장된 편집이 있으면 먼저 '저장해 둔 판'에 보관합니다. 일부 메신저는 긴 링크를 자르므로, 잘리면 '링크가 손상되었다'고 알립니다. 시드·건물 수·병원 설정을 바꾸면 편집 내용이 사라지므로 확인 창이 뜹니다.

### 고른 건물

건물을 누르면 패널에 다음 칸이 나옵니다 (편집 모드가 아니어도 바꿀 수 있습니다).

| 칸 | 동작 |
|---|---|
| 이름 | 바꾸면 범례·라벨·목록의 기준 이름이 함께 바뀝니다. |
| 번호 | 숫자를 적거나 ▲▼로 범례 순서를 바꿉니다. 운동장 같은 번호 없는 시설은 비어 있습니다. |
| 평면도 | 아래 '평면도·모양 편집' 참고. |
| 종류·외관·모양 | 종류를 바꾸면 그 종류의 설명·정보로 바뀝니다(모양·크기는 그대로). 모양은 일자·ㄱ자·ㄷ자·ㅁ자 중정·날개형·아트리움·계단식·쌍둥이·탑상형·자유형 등. |
| 방향·층수·폭·깊이 | 방향은 도(°), 정면이 남쪽일 때 0°. 막히는 값이면 가까운 자리로 조금 옮겨 맞추고, 그래도 안 되면 알려 줍니다. |
| 복제 | 같은 건물을 옆 빈자리에 하나 더 놓습니다 (`Ctrl+D`). |
| 이름표 | 숨기거나, 편집 모드에서 이름표를 끌어 옮긴 자리를 되돌립니다. |
| 도보 거리 | 위 '보기' 참고. |

단축키: 방향키 1m(`Shift` 5m) 옮기기(막히면 그 앞에서 멈춤), `R`·`Shift+R` 15° 돌리기, `Ctrl+D` 복제, `Delete` 지우기, `Esc` 선택 해제.

지도에서는 고른 건물에 폭·깊이(카메라 쪽 변)와 높이(가까운 모서리) 치수선이 붙고, 지도 위 막대에 바닥 크기와 층수가 나옵니다.

### 평면도·모양 편집

고른 건물 칸 위쪽의 **평면도**는 건물을 위에서 본 도면입니다. 정면이 아래로 오게 건물 기준으로 그리며, 모눈(확대 정도에 따라 간격이 바뀜), 덩어리별 층수(높을수록 진하게, 윗층 덩어리는 점선), 폭·깊이 치수선, 방위표(N), 축척 막대, 정면 표시와 표제란(도면 번호 A-번호, 모양, 규모, 바닥 상자, 건축면적, 연면적, 정면 방위)이 있습니다. `크게`를 누르면 큰 창에서 같은 편집기를 씁니다 (`Esc`로 닫기).

- **네모 손잡이**(오른쪽 변·정면 변)를 끌면 폭·깊이가 바뀝니다. 놓을 때 자리를 검사해, 막히면 가까운 자리로 조금 옮깁니다.
- **동그라미 손잡이**는 모양마다 다릅니다. ㄱ자 앞 날개 폭·뒤 동 깊이, ㄷ자 날개 폭·뒤 동 깊이, ㅁ자 동 두께, 본관형 가운데 동 폭, 아트리움 폭, 계단식 윗부분 폭, 쌍둥이 탑 폭, 탑상형 탑 폭·깊이. 끄는 동안 길이(m)를 보여 줍니다. 아래 막대로도 같은 값을 바꿀 수 있습니다.
- 계단식·쌍둥이·탑상형·병원형은 **저층부** 층수, ㄱ자·병원형은 **좌우 뒤집기**, 일자·ㄱ자·ㄷ자·ㅁ자·탑상형은 **지붕**(외관 따름·평지붕·경사 지붕)을 고릅니다. `기본 비율로`는 이 값들을 모양의 기본값으로 되돌립니다.
- **자유형**: `칸으로 고치기`(또는 모양 칸에서 '자유형')를 누르면 지금 모양을 약 6m 칸으로 옮깁니다 (중정은 빈칸, 탑은 높은 칸). 칸을 누르거나 끌면 붓 층수로 칠하고, 같은 층수인 칸을 누르거나 오른쪽 버튼·`지우개`로 누르면 비웁니다. 칸 수(가로×세로, 최대 24)를 바꾸면 가까운 칸 값을 옮겨 옵니다. 층수 막대는 가장 높은 칸을 기준으로 모든 칸을 비율대로 바꿉니다. 높이가 같은 칸끼리 덩어리를 이루어 계단처럼 쌓이고 지붕은 평지붕입니다.
- 자리 검사(겹침·도로)는 모양과 관계없이 바닥 상자로 하므로, 날개를 줄이거나 칸을 비워도 그 빈 곳에 다른 건물을 붙여 놓지는 않습니다.
- 모양 값은 JSON·저장해 둔 판에 담기고, 목록 모드에서는 목록 칸에 `형태 날개30 깊이55 반전 저층2 경사지붕`(%·층수), 자유형은 `모양 자유형 | 평면 4x3 3300/3311/0011`(가로×세로, 뒤쪽 줄부터, 칸 층수 0~9·a~p=10~25)로 적힙니다.

### 이름표·여러 개 고르기

- 편집 모드의 선택·이동 도구에서 지도 위 이름표를 끌면 이름표만 옮겨집니다(지시선으로 건물과 이어짐). 옮긴 이름표는 겹침 회피보다 앞서 그 자리에 그립니다.
- `Shift`를 누른 채 누르면 여러 건물·상징물을 묶어 고르고, `Shift`를 누른 채 빈 곳을 끌면 상자 안의 것을 모두 고릅니다. 묶음 중 하나를 끌거나 방향키를 누르면 함께 움직이고, `R`은 각자 제자리에서 돌리며, `Delete`는 함께 지웁니다. 묶음은 모양을 유지한 채 전체가 들어갈 수 있을 때만 움직입니다 (끌어 놓은 자리가 막혔으면 가까운 자리를 찾고, 방향키는 막히면 멈춤).

### 길·나무

- **길 그리기**: 도로(차도, 폭 9m)나 산책로(폭 4m)를 고르고 지도를 눌러 점을 찍습니다. 두 번 누르거나 `Enter`로 끝내고, `Backspace`로 마지막 점을, `Esc`로 전체를 취소합니다. 그린 도로 위에는 건물을 둘 수 없고, 걷는 길 찾기에도 쓰입니다.
- **지우기** 도구로 건물이 없는 곳의 길을 누르면 그린 길은 지워지고, 캠퍼스 안 도로·연결로는 숨겨집니다(순환도로·간선도로는 지울 수 없음). `지운 캠퍼스 도로 되살리기`로 모두 되돌립니다.
- **나무**: 붓(심기·베기)과 반경을 고르고 누르거나 끌어서 칠합니다. 벤 곳은 자동으로 자라는 나무와 숲도 치우고, 나중에 칠한 것이 앞선 것을 덮습니다.

### 메모 핀

`메모 핀` 도구로 지도를 누르면 그 자리에 핀을 꽂고 메모 창이 열립니다. 제목(24자)·내용(500자)·색(빨강·파랑·초록·주황·보라)을 적고, 창에는 배치도 칸과 가까운 건물이 나옵니다. 편집 모드의 선택·이동·메모 도구에서 핀을 끌어 옮기고, 핀을 고른 채 `Delete`로 지웁니다(편집 모드가 아니어도 핀을 눌러 읽고 고칠 수 있음). 핀은 조감도(표시 칸 '메모 핀'으로 끄고 켬)·배치도(M1… 번호와 목록)·설정 글 내보내기('## 메모')·JSON·링크·저장해 둔 판에 담기고, 건물 목록을 다시 적용해도 남습니다. 핀은 지면 좌표에 꽂히므로 건물을 옮겨도 따라가지 않습니다.

### 층 평면·호실

평면도의 층 칸에서 `1층`·`2층`…을 고르면 그 층의 평면이 나옵니다. 덩어리 단면을 직사각형 동으로 나누고, 동의 깊이에 따라 가운데 복도 양쪽 실(14 m 이상), 한쪽 복도(7.5 m 이상), 복도 없음으로 실을 나눕니다. 긴 동(30 m 이상) 양 끝에는 계단, 가장 큰 동에는 엘리베이터·화장실, 1층 정면 가운데에는 로비를 둡니다. 실 이름은 건물 종류를 따릅니다(강의동: 강의실·교수 연구실, 공학·자연: 실험실·연구실, 기숙사: 호실, 병원: 진료실·병실, 도서관: 열람실 등). 체육관(경기장·관람석)·공연장(객석·무대)·원형 건물은 따로 그립니다.

호실 번호는 층 번호 + 순서(201, 202 …)입니다. 실을 누르면 아래 칸에서 이름(예: 수학과 사무실)을 붙이거나 비워서 지웁니다. 이름은 평면도·설정 글 내보내기(시설 아래 '- 312호: …')·JSON에 담깁니다. 평면은 건물 모양·크기·종류로만 정해지므로, 모양이나 크기를 바꾸면 번호가 다시 매겨져 붙인 이름이 다른 실로 갈 수 있습니다. 표제란에 그 층의 호실 범위가 나옵니다. 실제 건축 평면이 아니라 설정용 어림입니다.

### 저장해 둔 판

`저장해 둔 판`을 열고 이름을 적어 `저장`하면 지금 상태(배치·편집·건물 목록·계절·시간·시점·주변)를 이 브라우저에 남깁니다. 이름을 비우면 '대학이름 1'처럼 짓고, 같은 이름이면 확인 후 바꿉니다. 최대 20개이며 넘치면 가장 오래된 판부터 지웁니다. 목록에서 골라 `불러오기`(또는 두 번 누르기)·`지우기`를 합니다. 저장하지 않은 편집이 있으면 불러오기 전에 묻습니다. 브라우저 데이터를 지우면 함께 사라지므로, 오래 보관하거나 다른 기기로 옮길 판은 `JSON 저장`을 쓰세요.

## JSON 형식

`JSON 저장`은 `campus-map/v1` 형식으로 옵션(시드·건물 수·병원·계절·시간·시점·주변, 목록을 썼다면 그 목록 글)과 배치(대학 이름, 번호 순서대로의 건물·광장·운동장 — 종류·이름·중심 좌표(m)·회전·폭·깊이·층수·외관·모양·모양 조절 값(날개·깊이·저층부·반전·지붕, 자유형 칸)·손으로 고정했는지·이름표 위치, 호실 이름, 상징물 — 종류·이름·좌표, 그린 길·숨긴 도로 번호·심은 곳·벤 곳, 메모 핀)를 담습니다. 옵션에는 캠퍼스 유형·밀도도 들어갑니다(없으면 전원형·보통으로 읽음). 저장해 둔 판도 같은 형식입니다. 불러올 때 모든 값을 검사하고, 범위를 벗어나거나 알 수 없는 종류가 있으면 거부합니다.
